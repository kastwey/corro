# Palabras prohibidas inicial

Dos equipos iguales alternan turnos de pistas habladas con temporizador. El portavoz describe el objetivo sin decirlo ni usar las palabras prohibidas; un compañero adivina y un supervisor rival señala ambos tipos de infracción. El chat de voz es opcional y Corro nunca graba ni transcribe el habla.

El anfitrión elige un idioma común para las palabras entre los mazos reales del paquete. Todos usan el mismo contenido de objetivos y palabras prohibidas aunque sus interfaces estén en idiomas distintos.

El portavoz comprueba por el chat de voz o en persona que todos estén preparados y después inicia el temporizador. Ningún otro jugador tiene que confirmar que está listo en Corro.

## Cómo jugar con lector de pantalla

El foco entra en la superficie de funciones. Usa Tab y Shift+Tab para moverte entre la carta multilínea protegida y tus acciones disponibles. La carta permite mover el cursor, seleccionar y copiar, pero bloquea la edición. Pulsa Intro para iniciar cuando seas portavoz, R para oír el tiempo restante, V para señalar el objetivo o una palabra de la lista cuando seas supervisor, S para oír tu función y puntuación, Shift+S para la puntuación rival, Ctrl+F6 para recorrer los paneles y Ctrl+Shift+R para el chat de texto.

## Ayuda

- **F1** abre esta guía.
- **Ctrl+F1** muestra los atajos activos.
- **Ctrl+Shift+F1** lee las reglas efectivas.
- **Ctrl+F6** recorre los paneles de la página.
- **Ctrl+Shift+R** abre el chat de texto.
